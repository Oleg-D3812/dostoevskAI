1
Input / LLM extraction

Извлечение единицы наблюдения

Берётся непрерывная цитата, где словами выражено эмоциональное или психическое состояние героя.
+

LLM получает текст главы с пронумерованными предложениями, именем героя и алиасами. Источник состояния может быть у рассказчика, самого персонажа или другого персонажа.

Что считается наблюдением

Непрерывная цитата о состоянии героя. Не отдельное слово и не целая глава.

Ограничение

Телесные проявления сами по себе не считаются достаточным основанием без явного эмоционального смысла.

2
Filtering

Проверки и правило допуска

До финального набора доходят только цитаты, прошедшие дословность, эмоциональную релевантность и атрибуцию.
+

Дословность

Цитата должна быть точной подстрокой исходного текста.

Эмоциональная релевантность

Цитата сама по себе должна описывать состояние человека.

Атрибуция

Состояние должно принадлежать целевому персонажу.

Повторный аудит

Первичные отрицательные и неоднозначные решения повторно проверяются отдельным LLM-вызовом.

Iₜ = Cₜ Eₜ Tₜ = 1
3
VAD scoring

Оценивание состояния в координатах VAD

Каждый допущенный фрагмент получает один вектор Valence–Arousal–Dominance.
+

Текущий пайплайн использует одну VAD-оценку на фрагмент. Для смыслового разрешения подаются полные соседние предложения до и после цитаты, отдельно до 350 символов на каждую сторону.

xₜ = (Vₜ, Aₜ, Dₜ)ᵀ ∈ [-1,1]³

Valence

От крайне неприятного состояния к крайне приятному.

Arousal

От покоя и заторможенности к возбуждению.

Dominance

От беспомощности к контролю над собой или ситуацией.

Важно

Центрирование, z-стандартизация и PCA для текущей кластеризации не применялись.

4
Validation

Предварительное исследование устойчивости к контексту

Проверяется, насколько VAD меняется при повторных вызовах и при расширении контекста.
+

В раннем эксперименте рассматривались окна h ∈ {0,1,2,3,5,8} предыдущих фрагментов и по 7 оценок на каждую пару «фрагмент × окно».

Повторная стабильность

Используются медиана и межквартильный размах для каждой оси.

mₜ,ₕ,ₐ = medianᵣ xₜ,ₕ,ᵣ,ₐ IQRₜ,ₕ,ₐ = Q₀.₇₅ − Q₀.₂₅

Чувствительность к контексту

Сравнивается сдвиг медианного VAD при изменении ширины окна.

Δₜ(h,h′) = ‖mₜ,ₕ′ − mₜ,ₕ‖₂ diamₜ = maxₕ,ₕ′ Δₜ(h,h′)

Диагностические пороги

Нестабильный: max IQR ≥ 0.25. Чувствителен к контексту: max IQR < 0.25, но diam ≥ 0.35.

Что выбрано дальше

В финальном пайплайне используется предложенческий контекст вокруг TARGET; сам лимит 350 символов не выводится строго из этого эксперимента, но исследование подтверждает необходимость контролируемого контекста.

После получения подтверждённых VAD-векторов пайплайн расходится на две ветви: основная — финальное сопоставление с Плутчиком по статистическим моделям эмоций; исследовательская — поиск структуры состояний через кластеры и их именование.
5
Step 8 core

Статистические эталоны 8 эмоций Плутчика

Для каждой эмоции строятся средний VAD-вектор и полная ковариационная матрица.
+

Эталоны берутся из лексического справочника. Для anger и fear выполнялся дополнительный отбор слов по семантической уверенности, затем по каждому списку напрямую считались средние и ковариации.

μₑ = (1 / Mₑ) Σ yₑ,ₗ Σₑ = (1 / (Mₑ − 1)) Σ (yₑ,ₗ − μₑ)(yₑ,ₗ − μₑ)ᵀ

8 эмоций

joy, trust, fear, surprise, sadness, disgust, anger, anticipation.

Важно

Это статистические параметры справочника, а не фиксированные теоретические точки.

6
Fragment → emotion weights

Сопоставление фрагмента с 8 эмоциями

Каждый фрагмент сравнивается со всеми восьмью моделями эмоций.
+

Сначала вычисляется расстояние Махаланобиса до каждой эмоции, затем полная гауссовская плотность. После нормировки получаются относительные веса по восьми эмоциям.

δ²ₜₑ = (xₜ − μₑ)ᵀ Σₑ⁻¹ (xₜ − μₑ)
fₑ(xₜ) = exp(−δ²ₜₑ / 2) / ((2π)^(3/2) |Σₑ|^(1/2))
P(e | xₜ) = fₑ(xₜ) / Σⱼ fⱼ(xₜ)
  • Мера учитывает не только расстояние до среднего, но и форму распределения эмоции.
  • Каждый фрагмент распределяется между всеми 8 эмоциями, категории «вне модели» нет.
7
Aggregation

Агрегация по главам

Постериорные веса отдельных фрагментов суммируются и усредняются на уровне главы.
+

Если в главе h есть Nₕ фрагментов, для каждой эмоции сохраняются две агрегированные меры.

Sumₕ(e) = Σₜ∈ₕ P(e | xₜ) Meanₕ(e) = (1 / Nₕ) Σₜ∈ₕ P(e | xₜ)

Среднее вычисляется после нелинейного преобразования каждого VAD, поэтому оно не равно вероятности для среднего VAD главы.

8
Outputs

Итоговые профили: 8 эмоций и 16 компонентов

Из восьми базовых весов строится как базовый профиль, так и расширенное представление с первичными диадами.
+

8 базовых эмоций

На уровне фрагмента и главы сохраняются веса для joy, trust, fear, surprise, sadness, disgust, anger и anticipation.

Фрагмент → 8 relative weights P(e | xₜ)
Глава → Sumₕ(e) и Meanₕ(e)

16 компонентов

Включают 8 базовых эмоций и 8 первичных диад: love, submission, awe, disapproval, remorse, contempt, aggressiveness, optimism.

Непрерывная сила диады:
dᵢⱼ = 2√(pᵢpⱼ)
Совместное нормированное разложение:
r(Eᵢ)=pᵢ², r(Dᵢ,ᵢ₊₁)=2pᵢpᵢ₊₁
q_c = r(c) / Z, где Σq_c = 1
A
Cluster branch

Поиск структуры состояний

Подтверждённая исследовательская ветвь: сравнение семейств кластеризации и финальный выбор K-Means.
+

Ранний Experiment 2B сравнивал 33 решения: K-Means, GMM и HDBSCAN. В текущем пайплайне как рабочий метод выбран K-Means для каждого героя отдельно.

Сравнивались

K-Means: K=2…10; GMM: K=2…10; HDBSCAN: разные min cluster size и min_samples.

Финальный выбор

K-Means по диапазону K ∈ {3,4,5,6}, 50 инициализаций, seed 42.

J_K = Σᵢ Σₜ∈Cᵢ ‖xₜ − cᵢ‖₂² cᵢ = (1 / nᵢ) Σₜ∈Cᵢ xₜ
B
K selection

Выбор числа кластеров

K выбирается по сочетанию компактности, разделённости, устойчивости и размера минимального кластера.
+

Метрики

Silhouette, Calinski–Harabasz, Davies–Bouldin, средний ARI по 100 подвыборкам, доля минимального кластера.

Итоговый балл

Q(K) = (1/5) [ Z_S + Z_CH − Z_DB + Z_ARI + Z_(n_min / N) ]

Выбирается K с максимальным Q.

Устойчивость

100 повторений на случайных подвыборках ≈80% без возвращения; каждое решение сравнивается с исходным через ARI.

Выбранные K

Раскольников — 4, Софья Мармеладова — 3, Свидригайлов — 3.

C
Naming

Интерпретация и названия кластеров

После численного выделения кластеров им присваиваются содержательные названия по центральным примерам.
+

Для каждого кластера сохраняются центроид, размер, среднеквадратический радиус и ближайшие/периферийные фрагменты. Для именования выбираются 8 ближайших уникальных цитат, которые подаются в LLM вместе с VAD и координатами центра.

rᵢ = √[(1 / nᵢ) Σₜ∈Cᵢ ‖xₜ − cᵢ‖₂²]
  • Названия не влияют на границы кластеров и не участвуют в выборе K.
  • Это интерпретация центральных примеров, а не новая модельная оптимизация.
D
Auxiliary step 7

Кластерный профиль Плутчика

Дополнительная схема: центроиды кластеров сравниваются с точечными VAD-прототипами эмоций.
+

Это отдельная подтверждённая ветвь Step 7, но не финальный способ расчёта итоговых профилей. Она полезна для обзорного сопоставления структуры состояний героя с прототипами эмоций.

αᵢ = nᵢ / N dᵢₑ = ‖cᵢ − pₑ‖₂ sᵢₑ(σ) = exp(−dᵢₑ² / (2σ²)) Fₑ(σ) = Σᵢ αᵢ sᵢₑ(σ)

Здесь получаются восемь независимых мер сходства, а не нормированное распределение вероятностей.
